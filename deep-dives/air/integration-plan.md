# AIR → DCA Integration Plan

## Phase 1: Nightly Synthesis
- During heartbeat quiet hours (23:00-08:00), run synthesis on the day's events
- Generate morning briefing: key decisions, completed tasks, upcoming items, insights
- Deliver via the user's preferred channel (Telegram, email, dashboard)
- Store synthesis in memory files for continuity

## Phase 2: Living Documentation
- Agent conversations automatically update project documentation
- No separate "write docs" step — it happens naturally
- Wiki structure grows from the conversation topics
- Cross-link related concepts automatically

## Phase 3: Dual-Mode Operation
- **Async Mode**: Background processing, synthesis, research
- **Real-Time Mode**: Interactive sessions, immediate responses
- Auto-detect mode based on user activity
- Seamlessly switch between modes
