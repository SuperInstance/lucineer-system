# lucid-dreamer → DCA Integration Plan

## Phase 1: Three-Layer DCA Architecture
- **Layer 1 (Engine)**: Core DCA primitives — scheduling, memory, budget, routing
- **Layer 2 (Tutor/Mediator)**: Agent orchestrator — adapts to user, tasks, context
- **Layer 3 (Interface)**: User-facing — Slack, Telegram, CLI, web dashboard

## Phase 2: Resonance-Based Agent Assignment
- Compute resonance scores between agents and tasks
- Match agents to tasks based on complementary strengths
- Factor in learning velocity and preferred working style
- Reassign dynamically as resonance shifts

## Phase 3: Iterative Feedback Loop
- Every agent action produces an observation
- Observations feed back into strategy selection
- Tutor-like intervention system (celebrate, redirect, hint, deepen)
- Conservation of total fleet attention/compute

## Phase 4: Design Manifesto
- Write a vision document for DCA similar to this one
- Define the math-as-mechanic principle
- Establish the polyglot philosophy (right language per layer)
- Document the three-layer separation
