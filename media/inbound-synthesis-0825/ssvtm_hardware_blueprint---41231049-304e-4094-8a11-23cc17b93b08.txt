================================================================================
The entire hardware system maps physical input/output lines, status registers, 
and low-rank transformer matrices directly onto a continuous 32-bit address space.

--------------------------------------------------------------------------------
Base Address Range       | Component Designation  | Description
--------------------------------------------------------------------------------
0x4000 0000 - 0x4000 0FFF | PERIPHERAL_BUS_ADC     | Analog-In/Direct DMA Buffers
0x4000 1000 - 0x4000 1FFF | REG_POSTURE_MATRIX    | Hardware Gate & Control Registers
0x4000 2000 - 0x4000 3FFF | ATTN_REFLEX_LAYER     | Tier 1 / Heads 1-4 Weights (S1)
0x4000 4000 - 0x4000 FFFF | ATTN_COGNITION_LAYER  | Tier 2-3 Deep Manifold (S2)
0x0800 0000 - 0x08FF FFFF | FLASH_ROM_PCM_STORE   | Pre-compiled Primitive Audio Storage

--------------------------------------------------------------------------------
CRITICAL SYSTEM REGISTERS
--------------------------------------------------------------------------------
[0x4000 1000] SYSTEM_POSTURE_REG (8-bit, Read/Write):
              - 0x00: IDLE_CLEAR   -> Routes input directly to Reflex heads.
              - 0x01: SYSTEM_BUSY  -> Diverts input through active Cognition loop.
              - 0x02: FAULT_HALT   -> Immediate lock; forces zero-prose override loop.

[0x4000 1004] ATTN_MASK_REG (32-bit, Read/Write):
              - 0x0000 FFFF: MODE_REFLEX_ONLY (Blocks layers 5-32 execution)
              - 0xFFFF FFFF: MODE_FULL_COGNITION (Unlocks full MoE array)

[0x4000 1008] DMA_OUT_TARGET_ADDR (32-bit, Read/Write):
              - Contains the absolute memory address of the outbound audio payload.
