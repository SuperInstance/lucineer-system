$$z = x + y\omega$$ 
Where $\omega = e^{2\pi i / 3} = -\frac{1}{2} + i\frac{\sqrt{3}}{2}$ represents the primitive cube root of unity.

* The Real Axis (x) maps the strict, rational integer time markers computed directly from Plainsong's bar subdivisions.
* The Eisenstein Axis (y) tracks structural macro-variables, such as tempo changes, swing percentages, and microphone distances calculated by Plainsong's acoustic stage model.

## The Snap Algorithm

   1. Convert raw input coordinates (x,y) into fractional lattice approximations:
   $$r = x$$ 
   $$g = \frac{2}{\sqrt{3}} y$$

   $$r_{\text{low}} = \lfloor r \rfloor, \quad g_{\text{low}} = \lfloor g \rfloor$$ 
   3. Compute the structural distance error using pure integer bounds checking. Your FLUX engine tracks the calculation using an 8-bit error mask:
