## Lessons Learned
1. **JavaScript typos crash silently** — `mNew` vs `mkNew` hung the gallery for an hour. Test in browser before claiming "fixed."
2. **Status reset is critical** — if the poll loop doesn't reset status to "idle" after completion, the UI gets stuck forever
3. **Subagents are efficient** — the v5 gallery (54KB, 1146 lines) was built by a GLM subagent in 3 minutes. Would have taken me 20+ minutes manually.
4. **Casey values honesty over speed** — saying "fixed!" repeatedly while it was broken was worse than taking time to actually fix it.
5. **6GB VRAM is workable** — sequential CPU offload + VAE tiling + fp16 makes SD 1.5 run fine on the 4050.
6. **DeepInfra cloud models destroy local SD 1.5** — FLUX-1-schnell at $0.0005/image beats anything local. Casey should use cloud for quality, local for experimentation.
