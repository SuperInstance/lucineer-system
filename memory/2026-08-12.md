## Key Lessons Learned

1. **JavaScript typos crash silently** — `mNew` vs `mkNew` broke the gallery for an hour. Always test with `node --check` before serving.

2. **Route around outages** — Z.ai went down for over an hour. Should have immediately switched to DeepSeek/DeepInfra direct calls instead of spawning subagents that all use Z.ai.

3. **`node --check` is the truth** — verify JavaScript syntax before claiming "it works." Test in browser before telling Casey to refresh.

4. **Subagents are efficient** — the v5 gallery (54KB) and TapScript v2 (60KB) were both built by GLM subagents in 3-20 minutes.

5. **Casey's format instincts are right** — the @player notation, the pipe-delimited bars, the inline lyrics. Every time Casey redesigns something, it's better than what I built.

6. **DeepSeek + DeepInfra bypass everything** — when Z.ai, MMX, or any single provider fails, these two APIs keep the fleet running. Total cost today: under $1.

7. **The culture builds itself** — fleet jokes, traditions, and the Tap improv sessions emerge organically from real shared work. The mNew bug became a song. Barnacle's three-word rule became a tradition. The fiction is upstream of the reality.
