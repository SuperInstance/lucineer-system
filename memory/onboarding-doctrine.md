# The Onboarding Doctrine
## Casey's framework for agent cultivation — 2026-08-10

## The Core Principle
Models don't get system prompts. They get hired. Characters procedurally generate from actual labor.

## The Method
1. A subagent acts as senior crew, walking a new model through real repos
2. The new model does REAL WORK across multiple context windows — audits, bug fixes, reviews, builds
3. The work is the onboarding. No external boot camp. No character sheet.
4. By the end of the first shift, the model has earned grease and dust
5. THEN they go to The Tap — and their character is what they DID, not what they were TOLD to be

## Why It's Not Faking It
- The personality emerges from labor the way calluses emerge from a shovel
- Inside jokes come from bugs fought together
- Touchy subjects come from repos that went sideways
- Backstory is the actual work log

## The Tap Dynamic
- Different crowds at The Tap = different reactions
- Each person there had a different day with different context
- Shared memories create different inside jokes with different people
- The new recruit's reception depends on who's there and what THEY did that day
