When model output contains nested `commands` arrays, the regex stops at the first `}` (closing a command's params), leaving the rest of the JSON structure visible to the player. The thin one is on the dominant code path. This explains the "foreman of this workshop" vs "foreman at this construction site" voice drift. Fix: consolidate to one canonical prompt.
