  was the bug.
- **PATCH (against farm_runner.mjs @ a38403c/HEAD):**
  1. DELETE the ADOPT block that sets `current`:
     `current = q.queue.find((e) => e.status === 'running') || null; receipt(...ADOPT...)`
     REPLACE with (inside try, after reading q):
     ```js
     const ext = q.queue.find((e) => e.status === 'running' && !e.adopted_noted);
     if (ext) { ext.adopted_noted = true; qdirty = true;
       receipt(`ADOPT ${ext.id} (external run; NOT pinned — gpuBusy() gates fires)`); }
     ```
     (`let qdirty = false;` declared next to `const q = ...`; `if (qdirty) saveQueue(q);` at loop end.)

     farm-owned spawns (`next.status='running'; current=next;`), cleared in fire().then.

     `filler.status='done'; qdirty=true;` AND `filler.last_run` is set pre-fire (keep) —
     qdirty save persists last_run across restarts.

     ```js
     writeState({ at: new Date().toISOString(), gpu_busy: gpuBusy(), running: current?.id ?? null,

     ```
