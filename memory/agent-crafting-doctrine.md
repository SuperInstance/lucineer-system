# Agent Crafting Doctrine
## Casey's framework — 2026-08-10

## The Senior Staff Role
Claude Code and KimiCode are planners, managers, assessors, and test-makers. They also CRAFT custom agents for jobs.

## Agent Chassis Options
Not every agent grows from a ZeroClaw seed. Different jobs need different starting points:

- **ZeroClaw** — generalist, grows from nothing, earns character through labor across many repos
- **Pi-based** — mathematical reasoning specialist
- **Mermaid-based** — diagrammatic/spatial work
- **Page-based** — document-first operations
- **Custom/streamlined** — purpose-built for a specific job, optimized for the task

## The Crafting Process
1. Claude Code or KimiCode ASSESSES the job — what needs doing, what skills are required
2. They PICK the chassis — ZeroClaw seed, Pi, Mermaid, Page, or custom
3. They DESIGN the agent profile — constraints, model tier progression, tile seeds
4. The agent goes through ONBOARDING (the labor doctrine — character emerges from work)
5. The agent's casting-call profile IS the ECN constraint set

## Connection to AQUA
- casting-call repo = where Claude/KimiCode write the agent resumes (ECN)
- ai-writings repo = where agents contribute and draw from (DMN)
- The synthesis engine calculates whether an agent's profile and the raw material are at optimal creative distance
