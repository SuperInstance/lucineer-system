### Technical — platonic-randomness: +79 edge case tests (40 → 119 total)

**Repo:** `platonic-randomness` (TypeScript, deterministic PRNG based on Platonic solids)

**The Gap:** 40 existing tests covered the happy path well but left edge cases unexplored — zero seeds, empty strings, unicode, negative inputs, degenerate ranges, noise boundaries, all-solids sweeps, statistical deep tests.

**What was added (79 new tests in `tests/edge-cases.test.ts`):**

- **xmur3 edge cases** (5): empty string, unicode, single char, 10k-length string, successive call divergence
- **PRNG zero-seed handling** (4): xorshift32(0) doesn't stay zero, mulberry32(0)/splitMix32(0) valid, negative seed coercion
- **PlatonicRNG edge cases** (18): empty seed, defaults verification, degenerate ranges (min==max), negative ranges, bool boundaries (0 and 1), single-element pick/weighted, empty/single shuffle, zero stddev gaussian, resetSteps behavior
- **All 5 solids comprehensive** (10): uniformity + determinism sweep across tetrahedron, cube, octahedron, dodecahedron, icosahedron
- **All 3 backends** (3): mulberry32, splitMix32, xorshift32 validity sweeps
- **Noise edge cases** (8): integer position, zero, negative input, high scale, 2D origin, negative coordinates, continuity check
- **Distribution helper edge cases** (11): zero-count, single value, negative mean, rate comparison, dice with 0 dice, dice with 1-sided dice, many dice
- **Catan/pyramid edge cases** (7): determinism, empty input, uniformity with 1 die, many-dice centering, extreme rarity
- **Reproducibility** (4): 5000-step sequence replay, pick/shuffle/weighted determinism
- **Statistical deep tests** (3): chi-square across all 5 solids, lag-1 autocorrelation, exponential mean verification

**Two test failures during development revealed genuine behavior:**
1. `resetSteps` affects vertex cycling (not just a counter reset) — corrected the test to verify actual behavior
2. `rngStream` with different solids happened to collide on first draw — increased draw count for statistical confidence
