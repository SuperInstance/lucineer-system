The `technician` repo is a voice-first agentic system setup — "builds the robot around the brain." It had only 87 tests covering voice-commands and brain-config. Four modules were completely untested.

**Found and fixed 2 real bugs:**

1. **`rp` regex false positive on `rpm`** — The game preset regex `/game|dnd|rp|character|quest|dungeon|npc/` matched `rpm` in engine-related intents because `rp` is a substring of `rpm`. Fixed with word boundaries: `/\b(game|dnd|rp|d&d|character|quest|dungeon|npc)\b/`.

2. **Name/persona default mismatch** — When no preset matched, `name` defaulted to `"System's Room"` but `persona` defaulted to `"Assistant"`. A SuperInstance named "System" with persona "Assistant" is confusing. Aligned both to "Assistant".
