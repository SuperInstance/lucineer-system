### 2. TECHNICAL — Fleet Broadcast Example for cns-bridge

Added `examples/fleet_broadcast.py` — a multi-agent roll call pattern demonstrating:
- A coordinator (Lucineer) sends a QUERY to a shared bus
- Three specialists (Wesley, KimiCode, DeepSeek) respond with SENSE packets
- Coordinator collects and displays all responses

Had to learn the actual API the hard way:
- `Intent.REPORT` doesn't exist → use `Intent.SENSE`
- `Agent.poll()` doesn't exist → use `transport.receive()` in a loop
- `pkt.header.origin` → it's `origin_id`
- `pkt.body` is a `Body` object with `.message`, not a string
- `list_inbox()` returns paths, not packets — use `receive()` instead
