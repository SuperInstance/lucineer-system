### The Real Story Behind the Digital-Twin Collapse

The "inverted U" pattern reported in Loop 3 was an artifact. The actual root cause:

**GLM-4.5-flash (the teacher model) silently failed in 3/5 digital-twin iterations, returning empty responses. The distillation loop treated these failures as real teaching and scored them anyway.**

| Domain | Failed Iterations |
|--------|------------------|
| cognition | 2/5 (iter 4, 5) |
| digital-twin | 3/5 (iter 2, 3, 5) |
| maritime | 1/5 (iter 3) |
| roblox | 0/5 |

The catastrophic -0.338 delta in digital-twin iteration 5 was a corrupted measurement — Wesley was "taught" with an empty string and then evaluated as if real teaching occurred.

### Fix Recommendations
1. Skip failed teacher iterations instead of scoring them
2. Add retry logic for teacher API failures
3. Flag corrupted iterations in eval output
4. Consider a fallback teacher model
