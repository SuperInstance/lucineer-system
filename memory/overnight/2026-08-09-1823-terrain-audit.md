## Bugs Found and Fixed

### Bug 1: "Occupants: none" / "Objects: none" creates phantom entities (CRITICAL)
- **Impact**: Any MUD room with `Occupants: none` got a phantom agent named "none" rendered in the 3D scene. Same for `Objects: none`.
- **Root cause**: Parser split "none" as a comma-separated list entry without filtering it.
- **Fix**: Added case-insensitive check for "none" before splitting.
- **Regression tests**: 9 tests in `TestNoneLiteral` class.

### Bug 2: TerrainCore crashes on missing files (MODERATE)
- **Impact**: `TerrainCore('/nonexistent/file.mud')` raised a bare `FileNotFoundError` with no helpful context.
- **Fix**: Added explicit existence check with descriptive error message including the path.
- **Tests**: 2 tests in `TestTerrainCoreErrors`.

### Bug 3: Rust SceneCache nukes all entries on overflow (MODERATE)  
- **Impact**: `SceneCache.insert()` in `terrain.rs` called `self.scenes.clear()` when full, evicting ALL cached scenes instead of one.
- **Fix**: Changed to FIFO eviction — removes oldest entry, preserves the rest. Also handles re-insertion into a full cache without eviction.
- **Tests**: Added `test_cache_eviction` Rust test.
