**BUG FOUND in FilterGate:** `filterFor(nil, userId)` crashes with "bad argument #1 to 'lower'" instead of returning nil. The `detectInjection(text)` function calls `string.lower(text)` before checking if `text` is a string. This violates the fail-closed contract: "On any error, return nil." The fix should be a type check at the top of `detectInjection` or a `pcall` wrapper in `filterFor` before the injection pre-check.

**Severity:** Medium — the fail-closed contract is the core safety guarantee. Any code path that passes nil to filterFor will crash instead of safely returning nil.

**Recommended fix:**
```lua
function FilterGate.filterFor(text: string, fromUserId: number): string?
    if typeof(text) ~= "string" then return nil end  -- add this
    ...
```

All 14 tests pass. Bug documented in test.
