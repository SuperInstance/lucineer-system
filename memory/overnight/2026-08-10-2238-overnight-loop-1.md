### BUG FOUND: Empty String Intent Validation
**Severity:** Low-Medium
**Location:** `envelope.ts`, `validateEvent()` function
**Description:** Empty string `''` as intent passes validation because:
1. Required field check: `event[field] === undefined || event[field] === null` — empty string is neither
2. Intent regex check: `if (event.intent && !INTENT_PATTERN.test(event.intent))` — `''` is falsy, so the check is skipped
**Impact:** An event with `intent: ''` validates as clean and could propagate through the system with no actionable intent.
**Documented in test:** Yes, with comment explaining the bug.
