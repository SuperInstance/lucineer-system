## Test Discoveries

- `BranchScore._to_unit_interval` treats values in range `(1.0, 5.0]` as grades (not raw scores). This is a domain-specific convention — the validator auto-scales. Worth noting for anyone reading the code cold.
- `_public_record` hides `answer` and `golden_answer` keys but `evaluate` still marks predictions as `correct=True` when they match, regardless of pipeline status. The `failure_rate` tracks status separately. This is by design — accuracy and failure_rate measure different things.
- `resolve_media_path` returns the input path as-is when the file already exists (even relative). It only resolves when the file doesn't exist at the candidate path.
- `file_to_data_url` uses the suffix as-is (only normalizes jpg→jpeg). Unknown extensions like `.xyz` stay as-is in the MIME type.
