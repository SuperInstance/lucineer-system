#### Bug 1: fleet-vessel `get_dir_size()` — HIGH SEVERITY
- **Bug:** `os.DirEntry` doesn't have `.size` attribute. Code used `entry.size` instead of `entry.stat().st_size`. The `AttributeError` was silently caught by a broad `except` clause, making `get_dir_size()` return 0 for ALL file sizes.
- **Impact:** ALL directory size checks were returning 0. The `rust_target_max_mb` and `node_modules` cleanup were completely broken — they'd never trigger because sizes were always zero.
- **Fix:** Changed `entry.size` → `entry.stat().st_size`
- **Tests:** 61 tests added covering constants, spec parsing, HTTP helpers, disk utilities, delete, git tracking, enforcement logic, PLATO integration, and load_specs fallbacks.
- **Repo:** study-fleet-vessel → pushed

#### Bug 2: study-constraint-theory-math `weyl_orbit()` — HIGH SEVERITY
- **Bug:** The D₆ Weyl orbit computation had incorrect conjugation entries. The code computed `(a, a-b)` for the conjugate instead of the correct `(a-b, -b)`. The docstring was right but the implementation was wrong.
- **Impact:** The D₆ orbit contained elements with DIFFERENT norms, violating the fundamental property that D₆ preserves the norm. For example, `weyl_orbit(4, 1)` returned pairs with norms {7, 13, 21, 37} when ALL should be 13.
- **Fix:** Corrected conjugation to `(a-b, -b)` and propagated to all conjugate × unit entries.
- **Tests:** 43 tests added covering norm formula, triple verification, primitivity, D₆ orbit, triple generation, density comparison, multiplication closure, parametric form, and number-theoretic properties (primes ≡ 1 vs 2 mod 3).
- **Repo:** study-constraint-theory-math → pushed
