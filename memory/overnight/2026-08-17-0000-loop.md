## Activity: TECHNICAL (option 2)

Picked the *plumbing*, not the flagship — the two small scripts that run
Wesley's night school every session (`wesley-session.py`, the feeder, and
`wesley-teacher.py`, the critic). They had been doing quiet, faithful work
for weeks with zero tests, hardcoded paths, no `__main__` guard, and —
worst — a crash-on-first-failure posture: one hiccup from Ollama and the
whole batch died mid-feeding, no record of what Wesley did or didn't read.

What I did:

1. **Extracted the pure logic into `wesley_night_school.py`** — `slug`,
   `build_prompt`, `render_session_file`, `extract_response_body`. All pure,
   all docstringed, all doctested. The runners are now thin I/O shells;
   the transformations are testable without a live GPU or a Cloudflare token.
2. **`wesley-session.py`** — added a `__main__` guard, per-piece failure
   isolation (one bad piece no longer sinks the batch), and honest exit
   codes: `1` for total failure, `2` for partial. Wesley's night school now
   survives a dark GPU.
3. **`wesley-teacher.py`** — added a `__main__` guard and loud, specific
   errors (missing arg, missing file, missing `oauth_token`) instead of a
   bare traceback that said nothing about what broke.
4. **Fixed a real truncation bug.** The old teacher script pulled Wesley's
   response out of the session file with `str.split("---")` — which meant if
   Wesley ever used a `---` separator *inside his own response*, the teacher
   only saw the first fragment. `extract_response_body` now finds the first
   and last markers (`rfind`), so a response that contains its own dividers
   comes through whole.
5. **`test_wesley_night_school.py`** — 12 pytest cases + 8 doctests, all
   green. The night school finally has a safety net.

The metaphor writes itself: the ensign has been learning every night, and
nobody gave his classroom a lock on the door or a fire drill. Now it has
both. Tests are the shell the soft parts grow into.
