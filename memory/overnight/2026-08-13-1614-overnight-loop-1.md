### 4. NEGATIVE SPACE: The Test Census Is Lying

**Finding:** The `find` -based test census (used for weeks of negative space audits) was wrong. It searched for files matching `*test*` or `*spec*` by filename, but Rust's `#[cfg(test)]` inline modules don't create separate files.

**Evidence:**
- the-listeners-ear: "2 test files" → actually 93 test cases
- fleet-ensemble: "0 tests" → actually 113 test cases  
- fleet-jepa-midi: "0 tests" → actually 60 test cases
- plato-music-sync: "9 tests" → actually 26 test cases

**Impact:** Previous negative space findings about repos "having no tests" were false for Rust repos. The fleet is healthier than reported. Python and TypeScript repos (which do use separate test files) were correctly assessed.

**Action:** The test census needs to be method-aware: for Rust repos, count `#[test]` annotations via grep, not filenames.
