## Loop 9: NEGATIVE SPACE — The Distillation Root Cause

### The Real Story
The digital-twin collapse is NOT overfitting. It's **silent teacher API failures**. GLM-4.5-flash returned empty responses in 6/20 iterations across all domains. The distillation loop scored these as real teaching.

### The Bug
1. Teacher API fails → empty response saved with `"success": false`
2. Loop continues to student phase anyway
3. Student gets empty/broken teaching prefix
4. Eval runs on corrupted result
5. Scores saved alongside legitimate iterations

### Fix Required
- Skip failed iterations
- Retry teacher with fallback model
- Flag corrupted eval data
