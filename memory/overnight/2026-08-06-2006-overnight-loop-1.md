## Key Discovery
The luau_strip polyfill was unconditionally setting `Vector3.new = Vector3`, overwriting any existing Vector3 implementation. This meant every Roblox module that used Vector3 was broken in the test harness if Vector3 was already provided by the mock. Fixed by making all polyfills conditional (`if not Vector3 then ...`). This same fix likely improves compatibility for many other repos.

The Instance.__index fix (checking rawget first) means mock instances can now have custom properties accessed via dot notation — critical for any module that captures references like `workspace.Terrain`.
