## Key Decisions Made Today

2. Python demoted to workshop/experiments
3. systemd for all services (no more tmux-based process management)
4. MemoryMax fences per service (OOM kills don't take down the fleet)
5. Provider-tagged index files (no more embedding provider breakage)
6. Circuit breaker pattern for all API calls (no more single-provider failures)
7. Streaming memory index (O(batch), not O(corpus))
8. Cotton/oakum approach to speech production: outline first, render later
9. Sound quality encoding system (warmth/brightness/breathiness/pace/reverb/proximity)
