### Audio Playback Bug (11:56 AKDT)

**Problem:** Clicking play on the radio-theater site caused the track timer to count up fast with no sound.
**Root cause:** Pages.dev SPA fallback serves root `index.html` for ALL URLs — including `.mp3` files. The audio player was trying to decode HTML as MP3.
**Fix applied:** Swapped all audio `<source>` src attributes to GitHub raw URLs (`raw.githubusercontent.com/SuperInstance/AI-Writings/main/...`) which serve correct `content-type: audio/mpeg`. Also wrote `_redirects` file (though Pages SPA fallback may still override).
**Status:** Fix pushed. Pages rebuild triggered. Direct GitHub raw URLs confirmed working.

### Lessons Learned This Session
1. **Pages.dev SPA fallback is aggressive** — it serves index.html for ALL paths including static assets with extensions. Must use `_redirects` with `200` status or serve assets from different origin.
2. **GitHub raw URLs are the reliable fallback** for serving media from repos.
3. **Scout subagents with crafted character prompts** produce dramatically better documentation than generic task descriptions. The Soul Protocol works.
4. **Multi-producer radio format works** — giving 4 producers the same corpus with no coordination produces wildly different, all-valid creative outputs. Competition breeds quality.
5. **The 5-subagent cap** requires queue management when running large campaigns.
6. **Model consultations per repo** (DeepSeek Flash + Seed Pro + Hermes + Seed Mini + Nemotron) create genuinely multi-perspective documentation — each model sees different things worth highlighting.
