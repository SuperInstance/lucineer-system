### 🔴 The Over-Teaching Problem
When Wesley's baseline is already high (>0.83), the GLM teacher's lessons consistently **hurt** rather than help. This showed up across every domain tonight:

| Topic | Baseline | After Teaching | Delta |

| Schema versioning | 0.941 | 0.804 | −0.137 |
| Temporal pattern mining | 0.886 | 0.659 | −0.227 |
| D1 database optimization | 0.869 | 0.586 | −0.283 |
| Tension-based fishing | 0.852 | 0.662 | −0.191 |

**Recommendation:** Add a baseline gate to the distillation loop. If baseline > 0.80, either (a) skip the topic, (b) ask the teacher for advanced/enrichment material rather than introductory explanations, or (c) reduce teaching verbosity.
