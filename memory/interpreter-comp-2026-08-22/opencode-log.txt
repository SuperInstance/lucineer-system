Written: `~/.openclaw/workspace/memory/interpreter-comp-2026-08-22/arch-opencode.md` (397 lines, under budget). The architecture, in brief:

- **§1 Architecture** — new sibling repo `SuperInstance/mahout` (elephant stays numpy-only). Elephant-side diff is ~40 lines: trigger metadata (`pulse`/`drift` + deltas) in `production-log.jsonl`, optional `roomd.py` drift daemon. mahout tails the log (systemd, not tmux), generates best-of-3 interpretations, chain-seals them (Ammann-bar lineage, crab-traps discipline).
- **§2 Schema** — structured-canonical JSON + ≤50-word story; fixed enums (`mechanism`, `phase`), quantized buckets, `contrast_links` (relativity via the sauna/plunge doctrine), and a load-bearing **phase certificate** (warmth = window decoration per REG-1, never narrated as room temperature).
- **§3 Judge** — 60% arithmetic / 30% model / 10% human: deterministic calibration scoring, LLM judge adapter (cold-started on Seed-2.0-pro), captain's 5/week anchor that freezes promotion if agreement <70%.
- **§4 Flywheel** — SFT cold start (~100 gold) → best-of-3 DPO pairs, weekly, ≥300 pairs to arm. Honest 6GB table: **Qwen3-4B trains (QLoRA ~5.2–5.5GB peak); 8B does not** — inference-only oracle. Promotion = 4-gate eval (frozen genesis-40 win-rate ≥55%, calibration, boilerplate-distance, JSON validity); rollback = "the symlink never moved."
- **§5 Merge** — **against**, with the phason argument as the kill-shot: an interpreter fused with Wesley can't certificate Wesley's fiber (you can't read your own γ). Wesley consults mahout like a deckhand reads a barometer.
- **§6 Failure modes** — 8-row table (drift-chasing, judge-sycophancy, boilerplate collapse, phason re-entry, Tap overfit, corpus rot, GPU contention, silent fallback), each with structural guard + detector.
