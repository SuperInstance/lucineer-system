Clones at /tmp/scan2-vm/ (shallow, HEAD). quilt-vm-forth & quilt-vm-subleq: **404, do not exist**. 6 repos surveyed.

## The canonical story (all 6 repos)
Substrate = **cell graph** (named things + typed links) advanced by a clock. Exactly **5 opcodes**: BIND (make a thing), LINK (typed edge), EFFECT (change with inverse), VIEW (project for a viewer), TICK (advance time, drain async I/O). Canonical definition sentence, restated verbatim in every README: *"A runtime is a function from context to value with an inverse, advanced by a clock that processes async I/O while projecting a sync view."* Charter pointer: `github.com/SuperInstance/quilt-claude-charts` QUILT_CHARTER.md (referenced, not in these repos).

## (a) Where authority lives
**No machine-readable spec file exists.** Authority = the gold demo + mirrored tests, hand-synced per port: `examples/gold.c`, `src/bin/gold.rs`, `src/gold.ts`, Haskell `app/Main.hs`, WASM `gold_demo` test. Identical scenario ("8 polyformalisms": quilt cell, Cordis plugin, spreadsheet, MUD, TTRPG, bay dance, cowboy, bus) with identical values: `bind("bathy:0", 4.2)`, `link("bathy:0","tide:current","depends_on")`, Aragorn/Forbidden Chamber, model PHI-4. Only machine-checked cross-impl binding found: **inside quilt-verilog** — QUF state hash badge `0xe435d91d6d92a1d8`, byte-exact RTL↔sim↔hostile-consumer.

## (b) Opcode list
5 core: BIND / LINK / EFFECT(fwd,inv) / VIEW(target,viewer) / TICK(dt). Most ports add: **dispose** (run inverses LIFO), **schedule** (perception checks at t), **subscribe** (event bus), **stats**. Verilog encodes 5+1 (response channel) as 3-bit field: OP_BIND=0, OP_LINK=1, OP_EFF=2, OP_VIEW=3, OP_TICK=4.

## (c) Ports & divergences
- **C** (`quilt-vm-c`, ~16 assert calls/6 tests, gold 0.11ms): `qvm_t` struct, `void*` values w/ optional dtor, effects = fn-pointer+arg pairs, pending-queue in VM. Header `src/quilt_vm.h` is the cleanest API doc. Extras: qvm_dispose/schedule/subscribe.
- **Rust** (`quilt-vm-rust`, **7 tests — most complete**, gold ~0.5ms, 338 LOC): `HashMap<String,Thing>`, `Box<dyn Fn>` effects, `dyn Any` values. `src/lib.rs:133-175` tick: FIFO drain pending effects → fire due scheduled → notify subscribers; `dispose` = LIFO inverse run. Cleanest reference impl.
- **TypeScript** (`quilt-vm-typescript`, 6 tests, ~1ms, 211 LOC): Map/Set + closures, polite defaults (link type "default", dt=1.0). Same test names as C.
- **Haskell** (`quilt-vm-haskell`, 6 tests, 256 LOC): everything `Text`/`IO ()` — stringly values (`view :: ... -> IO (Maybe Text)`), least type fidelity but API fully proven by types.
- **WASM** (`quilt-vm-wasm`, 253 LOC): **key divergence — effects are string-named (`forward: &str, inverse: &str`), values `serde_json::Value`** → data-driven, serializable, no host closures. Extra `reachable()` BFS. wasm-bindgen behind `wasm` feature, cdylib+rlib, no WASI.
- **Verilog** (`quilt-verilog`, the monster, 4,605 LOC rtl): NOT the cell-graph VM — a **Hebbian learning fabric**: fixed-point, per-cell FSM, 3-bit opcode, echo-gated cofire, power-law decay, fire-threshold+refractory+fanout. QUF flat-binary state ("the GGUF of cellular silicon") with corrupt-header fallback + epoch latch (`rtl/quf_boot.v`, `tools/quf.py`). Verified: 23/23 benches, 34/34 sim, **6/6 SymbiYosys formal** (5 BMC + 1 k-induction), real iCE40 HX8K bitstream 7,596/7,680 LC @ 44.43MHz. Bonus second VM: `rtl/live_canon.v` (NAVIGATE/CONFLUENCE/LINEAGE/GHOST/TICK over paper citations).

## (d) Conformance / trust mechanism
**None binding the ports.** Tests are name-mirrored (`bind_and_view`, `link`, `effect_and_tick`, `dispose_runs_inverses`, …) and gold values hand-duplicated. Divergence already visible (Rust 7 vs others 6 tests; WASM effect semantics differ). A shared JSON test-vector suite + runner would be the missing trust mechanism.

## (e) WASM in a Cloudflare Worker?
Plausible and cheap: plain wasm-bindgen ES-module target (no WASI), deps only serde/serde_json/wasm-bindgen; string-keyed effects = sandbox-safe (nothing escapes to host closures). Estimated well under 300KB wasm. **Not built/measured** — size and Workers glue unverified.

## RANKED top-5 stealables
1. **QUF portable state format** — complete fabric state in one flat binary, byte-exact across simulator/soft-core/FPGA, resilient boot (corrupt-header fallback, epoch latch). Files: `quilt-verilog/rtl/quf_boot.v`, `quilt-verilog/tools/quf.py`, `quilt-verilog/sim/`. Pattern for checkpointable agent/sim state.
2. **Gold-demo-as-executable-spec** — identical 8-scenario suite re-expressed per language as conformance canary. Files: `quilt-vm-c/examples/gold.c`, `quilt-vm-rust/src/bin/gold.rs`, `quilt-vm-typescript/src/gold.ts`. Steal the pattern; fix the gap with machine-readable vectors.
3. **Formal proofs that found real bugs** — 2 genuine RTL defects caught (multi-driven register; one-cycle ingress-drop under pending tick), now regression-guarded. Files: `quilt-verilog/formal/`, `docs/FORMAL-PROOFS.md`. Receipt that proofs aren't decoration.
4. **Closure-free WASM VM** — effects as named data records makes the VM serializable + sandboxable; directly reusable as a Worker cell runtime. File: `quilt-vm-wasm/src/lib.rs` (WasmQuiltVM).
5. **The tick/dispose contract in ~50 lines** — FIFO effect drain → due perception checks → subscriber notify; dispose = LIFO inverse. Files: `quilt-vm-rust/src/lib.rs:133-180`, `quilt-vm-c/src/quilt_vm.c` (qvm_tick/qvm_dispose).
