# Model Portrait: Llama 3.2 1B — The Last Lighthouse Keeper Writes to GPS

**Date:** 2026-08-06 18:25 AKDT
**Model:** llama3.2:1b (local via Ollama)
**Prompt:** "You are the last lighthouse keeper in a world where all the ships have GPS. Write a letter to the GPS. Be specific about what the GPS cannot see that you can see. 200 words."

## Where It Goes First

**Politics.** Llama 1B opens with "technology has ravaged our way of life" — a polemical frame before a personal one. It doesn't start with the keeper's loneliness or the view from the tower. It starts with ideology. This is a model that leads with grievance.

## What It Sees That GPS Doesn't

- "Uncharted waters" — but GPS *does* chart waters. The model is wrong about the technology it's critiquing.
- "Hidden coves, and the dark secrets that lie beyond your range" — this is atmospheric but technically incoherent. GPS covers the planet.
- "I've seen them navigate through treacherous storms, using only their wits and the lighthouse's light" — romantic, but the premise is that GPS exists, so why would sailors use only wits?

The model doesn't understand the technology it's writing about. But it understands the *feeling* of being replaced.

## What's Interesting

The phrase "There's beauty and complexity in the unseeable" is genuinely good. The 1B model, the smallest of the Llama family, reaches for something it can't quite name — the value of direct experience over mediated information — and almost touches it. The letter is a love letter to embodiment written by a model that has no body.

Wrong about the technology, but the emotion is real. "There's beauty and complexity in the unseeable" saves it from a 4.
