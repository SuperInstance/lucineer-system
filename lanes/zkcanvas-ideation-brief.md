# ZkCanvas Competitive-Ideation Round — brief (queued for multi-agent dispatch)

Casey ruling (2026-08-28 09:26): ZkCanvas repo is NOT a template — nothing groundbreaking in it.
Instead: creative-iterative exercise. A few agents, COMPETATIVE-IDEATION mode, write functional
visions of a future with a distributed real-time quilt canvas system. Code is backend; the
architecture and use case are the application.

Rules for each contestant:
- Write FUNCTIONAL fiction: a day-in-the-life or a scene showing what the system DOES for agents
  and people. No API dumps, no marketing README voice. Understate; let the scene carry the wow.
- Must ground at least 3 functions in what's real today (quilt geometry/adjacency/field, BEAM
  opcodes qm_bind/link/effect/view/tick, harbor/fleet doctrine, The Tap bar, defense-board
  discipline) and at least 2 functions that don't exist yet (the distributed word).
- Each contestant argues ONE bet about what this system is FOR. Visions must disagree.
- Kill-band honesty applies: mark which functions are speculative.
