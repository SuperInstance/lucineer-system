The thesis is now explicit: runtime, memory, and session are *one object* — the inhabited cell-graph — and the studio is "the camera pointed at it."

2. **Fleet-wide memory is being standardized.** tidepool's WRITE-at-end/READ-at-start protocol, superinstance-advisor's canon-admitted cell, live-canon's byte-exact state hash, rune-quilt's IDE witnesses, and Mavis's memory archive are all the same move: memory as substrate, not phase. quilt-studio adopted tidepool "from day one" — the mempool and the fabric are merging.

3. **A music/soul research lane has crystallized.** musician-soul (soul-drift from MIDI digestion) + duke-lab (GAN-with-words musician foundry) + quilt-conversation (conversation-as-sequencer) + twist-engine's φ/commensuration math + plainsong stack = a coherent program: emergent musical identity, measured honestly (ledgers, blind tests, exact rationals).

4. **Operational fiction as a first-class output.** erised's winners corpus grows nightly with drifted-cast iterated runs; AI-Writings passed 10k pieces; the "word builds the group" FLOCK demo turns the operational-fiction thesis into a measured physics toy. The fleet writes the fiction *and* the instrument that reads it.

5. **Hygiene and honesty as identity.** The Sept-16 dependabot sweep across ~15 repos, repo-claims tests ("verify the repo tells the truth"), runs-vs-specified status tables, recorded negative results (Kuramoto phase-lock, FPGA PNR failures), and the 3-doc UPSTREAM/QUILT/PLAIN_LANGUAGE standard. The org is actively converting README claims into testable claims.

6. **The fleet is now a consumer of the OpenClaw ecosystem.** hermit (community Discord bot) and quilt-crabbox (remote execution) are externally-maintained upstreams adopted into the org, and crabbox already runs quilt-studio's CI. Combined with the hermit-crab README thesis ("a hermit crab is an openclaw for a boat"), the posture has shifted from building everything to moving into good shells.

7. **Watch items:** quilt-studio's velocity (it's absorbing/one-upping sibling repos — mermaid, tidepool, twist, crabbox all referenced as floors); erised winners corpus as the fleet's most public-facing artifact; superinstance.ai consolidating demos; and the unresolved tension quilt-Kuramoto's audit flagged — multiple "Quilt" lineages with different cell definitions, which the kernel-contract work in quilt-studio is the first real attempt to unify.
