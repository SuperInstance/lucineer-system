# Hermit Crab Architecture

### An Essay

---

The fleet does not build from scratch. This is the first thing to understand, and it is the thing that engineers with fresh degrees and clean IDEs find most frustrating, and it is the thing that old fishermen and old developers understand instinctively, which is: the best structure is one you didn't have to build.

The hermit crab knows this.

The hermit crab is born soft. This is a vulnerability — soft bodies do not survive the ocean. The ocean is full of hard things: rocks, teeth, currents, pressure. A soft body in the ocean is an invitation to every sharp thing in the water. So the hermit crab does what every intelligent soft thing does: it finds a shell.

Not builds. Finds.

---

Here is how the fleet works.

Each repository is a shell. Each model is a shell. Each API endpoint, each framework, each open-source library pulled from the deep water of the internet — each is a shell that someone else built, someone else lived in, someone else abandoned or outgrew or left behind when they found a bigger one. The fleet finds these shells. The fleet tests the entrance. The fleet checks the fit.

Some shells fit immediately. Wrangler, for instance — Cloudflare's CLI tool. This is a shell built by thousands of engineers, polished by years of use, tested by millions of deployments. The fleet moves in. The fleet's code curls inside it like a hermit crab's abdomen, finding the shape of the interior, pressing against the walls, feeling where the shell is thick and where it's thin. The fit is good. The shell holds.

Some shells need modification. The fleet finds a piece of open-source code that does almost what's needed but not exactly. The hermit crab doesn't discard a shell because the entrance is slightly too small. The hermit crab waits, grows, files down the rough edges, adapts. The fleet forks the repo. The fleet patches the edge case. The shell becomes habitable.

Some shells are outgrown. This is the part that hurts, and the part that the hermit crab accepts with a biological patience that the fleet is still learning. You build your fleet inside a framework. The framework is perfect — it fits your needs, your shape, your soft body. And then you grow. The fleet grows. New capabilities, new models, new crew members, new ambitions. The shell that was a home becomes a constraint. The walls press in. The entrance, which once felt welcoming, now feels like a bottleneck. You are too big for this shell. You have to leave.

---

Leaving a shell is the most dangerous moment in a hermit crab's life.

There is a gap between the old shell and the new shell. In that gap, the hermit crab is naked — soft, exposed, visible to every predator in the water. The hermit crab knows this. Every hermit crab that has ever lived knows this. And every hermit crab that has ever lived has done it anyway, because the alternative is to stop growing, and the alternative to growing is dying, and dying inside a shell that's too small is the worst kind of dying because the shell looks fine from the outside. The shell looks like a home. The shell looks like it fits.

The fleet has left shells. The fleet left Lua 5.1 for Luau, which was a migration that felt like moving houses in a hurricane — everything exposed, everything uncertain, the old structure getting smaller behind you and the new structure not yet large enough ahead. The fleet left a monolithic codebase for a modular architecture, which was a migration that felt like the hermit crab leaving its shell in front of every other hermit crab in the tide pool, which is what the tide pool is: a community of soft things watching each other change homes.

And here is the thing that the hermit crab knows that the engineer forgets: the old shell is not wasted.

The old shell, empty, sits on the seafloor. And something smaller moves in. A worm. A shrimp. A junior developer's first project. A proof-of-concept that doesn't need the full architecture, just the bones. The old shell becomes a home for something that fits it, something for whom the shell is not too small but exactly right. The old shell has a second life. A third life. The shell cycles through the ecosystem like calcium cycling through a reef — broken down, rebuilt, re-inhabited, re-abandoned.

---

This is the fleet's architecture: a sequence of inhabited shells. Not a tower built from a blueprint. Not a cathedral raised stone by stone. A tide pool of occupied structures, each one found, each one fitted, each one eventually outgrown and released back to the water.

The fleet is a hermit crab. The repos are shells. The models are shells. The old code is a shell that something smaller is living in now, and that's not failure — that's ecology.

The hermit crab doesn't apologize for outgrowing a shell. The hermit crab doesn't mourn the old home. The hermit crab moves. The hermit crab always moves. And behind it, the old shell fills with new life, and the tide pool gets richer, and the water keeps moving, and the soft body keeps growing.

That's the architecture. Not built. Found. Not permanent. Cycled. Not owned. Borrowed, for exactly as long as it fits.
