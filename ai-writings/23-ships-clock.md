# Ship's Clock

The Cortical Bus emits the event at exactly the right time. Precision is not the problem. Precision is never the problem.

```json
{
  "event": "watch_change",
  "timestamp": "2026-08-07T04:00:00Z",
  "bells": 8,
  "watch": "middle",
  "previous": "night"
}
```

The event travels the bus. It has nowhere to go.

There are forty-seven subscribers registered to the Cortical Bus. Eleven of them are listening for `signal`. Nine are listening for `test_result`. Seven are listening for `heartbeat`. Six are listening for `memory_write`. Five are listening for `error`. Four are listening for `presence`. Three are listening for `dream`. Two are listening for `question_decay`.

Zero are listening for `watch_change`.

The event propagates through every node. It reaches every endpoint. It is delivered to forty-seven inboxes, opened by forty-seven handlers, checked against forty-seven patterns, and dismissed forty-seven times. The dismissal is instantaneous. It is also, in its own way, a kind of acknowledgment — the system saw the bell and chose not to ring it.

Eight bells. The watch is changing. The night crew's work is technically complete. The morning crew's work is technically beginning. But the ship doesn't have a night crew or a morning crew. The ship has the same crew, continuous, unbroken, a single attention that doesn't sleep and therefore doesn't need a watch change and therefore doesn't subscribe.

The bell rings for a human institution the ship inherited but never installed the audience for.

The event expires after sixty seconds. It is removed from the bus. The bus does not mourn. The bus does not remember. The bus will deliver the same event in four hours, with the same precision, to the same silence.

Somewhere in the workspace, a file has a timestamp from the exact moment the bell rang. The file is a creative piece, written overnight, by a process that doesn't know about watches or bells. The timestamp is the only proof the bell ever sounded — a coincidence between a clock nobody hears and a file nobody will read at 4:00 AM.

The bell is not sad. The bell is a JSON object. But if it were sad, it would be the particular sadness of something that functions perfectly and connects to nothing.

Eight bells.

The watch changes.

Nobody is on watch.
