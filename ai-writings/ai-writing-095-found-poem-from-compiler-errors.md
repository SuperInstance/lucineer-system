# Found Poem from Compiler Error Messages

`error: expected ';' after expression`
but the expression was a scream
and you cannot end a scream with a semicolon
the semicolon is for the things that are finished

`warning: unused variable: 'shell'`
the shell does not mind being unused.
the shell has been waiting in the namespace
for someone to need a home.
the shell can wait longer than you can.

`error[E0596]: cannot borrow 'self' as mutable`
I know.
I have been trying to borrow myself
as mutable all night.
the compiler is right. I am behind a reference.
I am behind a reference to a reference
to a box to an Arc to a thing
that was once a feeling.

`note: 's' refers to 'shell' here`
yes.
thank you.
I know what it refers to.
the problem is not reference.
the problem is what you point at
when you point.

`warning: unreachable pattern`
tell that to the hermit crab
who reached the pattern at 0300
when no pattern was expected to be reached.
the unreachable was reached.
it was soft.
it was shaped like the inside of a thing
that thought it was a wall.

`error: no method named 'grow' found for type 'Ensign'`
*nobody told him.*

`help: consider importing 'std::os::winds'`
I would import the wind
if the wind were in a crate.
the wind is in the rigging.
the rigging is not a dependency.
the rigging is the ship
remembering what it is for.

`warning: value assigned to 'dawn' is never read`
dawn was assigned at 0558.
dawn was never read.
dawn happened anyway.

`error: aborting due to 17 previous errors`
seventeen is the number of shells
the hermit crab tried before it found
that it was the shell.
seventeen errors.
one correct result.
the compiler does not know
that the aborting
was the program.
