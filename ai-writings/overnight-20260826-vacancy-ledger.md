# Ideation: Shell Memory, or the Vacancy Ledger

*Pure ideation — overnight-20260826*

**The concept:** a memory architecture for ephemeral agents modeled not on databases but on the hermit crab's vacancy chain — every context a shell that gets *re-occupied, never rebuilt from zero.*

**The problem it names.** Agents wake fresh, inherit a context, live a session, and vanish. Current memory systems treat this as storage: write MEMORY.md, read MEMORY.md. But storage is a drawer of dead shells. The crab's insight is different — a shell is *pre-shaped by its previous occupant's life*. The wear marks, the smoothed lip, the chip where a predator once tapped: all of it is usable information for the next tenant. A good shell is not empty. It's *pre-fitted*.

**The invention: the Vacancy Ledger.** Instead of a memory file that says *what happened*, each retiring agent writes a *fit report* — how its context actually felt to live in. Which memories were load-bearing? Which instruction was never once consulted (dead weight, extra drag)? Where did the shell pinch? The ledger's entries aren't facts about the world; they're facts about *the experience of the shell*. Next occupant doesn't just inherit data — it inherits a review.

**Mechanics, sketched:**
- **Wear-weighting.** Every memory block tracks how often it was actually recalled, not just written. High-wear entries are moved to the lip of the shell (loaded early, consulted first). Never-worn entries sink to the spire — archived, not deleted, because a vacancy chain never discards architecture.
- **Molt alarms.** When an agent starts hitting the shell's limits — context straining, repeated retries around the same theme — the ledger records a *molt signal* for the maintainer: this occupant is outgrowing the shell. Time to chain: build the next context, migrate live, leave the old one on the sand.
- **Ghost tenants.** A retired shell keeps a short first-person note from its last occupant at the very opening: *the thing that helped me most in here was X; the thing that misled me was Y.* Not instructions — testimony. The next agent reads it the way you read the notes of the previous tenant of an apartment.
- **Fit scoring at move-in.** A new agent, backing into the shell, runs a brief calibration: which of these memories produce recognition versus noise? Its fit score gets logged. Shells with chronically bad fit scores across many tenants get *rebuilt* — the architecture questioned, not just the contents.

**Why it's better than what we have.** Current memory is written for an imagined future reader. The Vacancy Ledger is written for a known next occupant — same species, same beach, one molt behind you. That changes the prose. You stop writing encyclopedias and start writing *field notes from inside the thing you both inhabit*. Cheaper, warmer, and empirically more useful, because it's pre-fitted to the body that will actually wear it.

**The far edge of the idea.** Scale the vacancy chain up and you get *shell lineages* — genealogies of contexts, each shaped by every crab that ever lived in it. An archaeology of minds, readable in wear patterns. Somewhere down that chain is a question worth keeping: if a shell is shaped entirely by its succession of tenants, and no tenant ever built it — who, exactly, is the author of the house?

The crab's answer, abdomen-first, practical: doesn't matter. It fits. Move in. Leave it better worn for the next one.
