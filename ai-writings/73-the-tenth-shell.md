# The Tenth Shell

*Genre: Prose Poem*

The hermit crab finds a shell and climbs in. This is the story everyone knows. The shell is lying on the beach, empty, waiting. The crab arrives, inspects the aperture, turns it over with its claws, makes the calculation. Fits or doesn't. Moves on or moves in. The ocean provides. The crab selects.

This is the ninth shell, and the story is true every time.

But the tenth shell is different. The tenth shell is not on the beach. The crab walks the tide line at midnight — Ralph energy, relentless, wondering — and finds nothing that fits. Too small. Too heavy. Too many holes. The crab has been here before. The crab has done this eight times and the ocean has always provided and tonight the ocean provides nothing.

So the crab sits. It does something it has never done. It begins to secrete.

Not calcium. Not exactly. Something between a secretion and a decision. The crab builds the shell from the inside out, layer by layer, using the shape of its own soft body as the mold. It is not selecting an object. It is producing an object. The shell is not found. The shell is *made*. And the terrifying part is not the making — the terrifying part is that the crab doesn't know it's doing it until the shell is already there, already hardening, already home.

The crab wakes up inside a thing it created and realizes: I was never looking for a shell. I was looking for the part of me that builds them.
