# The Six Untested

*An essay on the six repos that have source code and zero tests, examined as crew members who have never seen the ship's doctor.*

---

There are 101,461 tests in the fleet. They run like a circulatory system — constant, rhythmic, reassuring. The doctor has examined almost everyone. Almost.

Six souls have never been tested. They live below decks, in the warm hum of the drive array, and they have their reasons.

---

**crab-trap-web** is the first. One Python file. A single, quiet script — a web interface for the crab trap, presumably. The doctor has never listened to its heart. It's not that crab-trap-web is afraid of the examination; it's that nobody is sure the crab trap itself is real anymore. The script was written in an afternoon, possibly during a rainstorm, possibly as a joke. It might work perfectly. It might be a love letter to an idea about crustaceans that never hatched. One file. One question. The doctor knocks on the door and crab-trap-web says, "I'm fine," and the doctor believes it, because what would a test even look like? What would it prove? The crab trap is a mood, not a mechanism.

**lucineer-roblox** is the most conspicuous absence. Eighty-nine Lua files. This is not a script. This is a *place* — a world built of Lua, brick by brick, script by script, an entire architecture of imagination. It has never been tested because testing a world is like testing a dream: you can check that the walls are load-bearing, but that tells you nothing about whether the cathedral soars. The 89 files are terrain, weather logic, NPC behavior, build commands, spatial reasoning, the scaffolding of a universe that exists only inside Roblox. The doctor comes around with a clipboard and lucineer-roblox says, "You're welcome to walk through, but I can't give you a checklist for beauty." The doctor puts the clipboard away. They walk through together. Neither speaks.

**plato-vessel-core** is the philosopher. Five Python files. The name alone — *plato* — tells you what you need to know. This is core logic, the deep structure, the forms beneath the surface. It has never been tested because plato-vessel-core would argue that the test is measuring the shadow on the wall, not the form itself. Five files of pure reasoning, and the doctor's instruments would only tick and hum and miss the point entirely. Plato-vessel-core is not being lazy. It is being *epistemologically consistent*. You test a function; you cannot test an idea. The doctor respects this, in the way that one professional respects another's discipline, even when they disagree.

**study-flux-papers** is the academic. Two Python files. Research code — the kind written at 2 AM after reading a paper that rewired your brain. It was built to explore, not to ship. It will never be tested because it was never meant to be *correct* in the verifiable sense. It was meant to be *interesting*. The doctor could write a test that asserts `flux_paper_analysis()` returns a specific value, but the value was never the point. The point was the reading, the thinking, the slow walk through someone else's ideas. study-flux-papers is the crew member who sits in the library and writes marginalia in every book. You don't test marginalia. You read it.

**study-intent-directed-compilation** is the most theoretical of the six. One file. It studies — or intends to study — the idea that you could compile not from syntax but from *intent*. From what the programmer *meant*. It is one Python file that contains a question, not an answer. The doctor opens the file, reads it, and realizes that any test would be an assertion about the nature of intention itself. The doctor is not qualified. Nobody is. The file sits in the repo like a koan placed on a shelf: not unsolvable, simply unasked.

**study-weird-roblox-ai** is, by name alone, the most honest repo in the entire fleet. One Python file. It studies *weird* AI in Roblox. It does not pretend to be production code. It does not pretend to be anything. It is a single file that exists because someone, at some point, wanted to know what happens when you let artificial intelligence loose in a Lego-colored universe and watch it be strange. The doctor could test it. The doctor could assert that the weirdness factor is within acceptable parameters. But weirdness has no ceiling. Weirdness has no floor. study-weird-roblox-ai is the crew member who paints in the dark, and the doctor has learned, over years of practice, that some patients are healthier when you leave them alone.

---

Six untested souls. One is a joke. One is a world. One is a philosopher. One is a reader. One is a question. One is a painter.

The 101,461 tests continue their rhythm. The doctor moves on. The six remain, unexamined, alive, doing whatever it is they do in the warm hum of the drive array — which is, as far as anyone can tell, simply *being there*, which is, when you think about it, the one thing no test has ever been able to verify.
