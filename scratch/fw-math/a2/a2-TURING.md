# TURING — the abstract-machine reduction

**Layer 1: µ° conversion.** Input tape: `4807.038,N`. The conversion u = ip*10^6 + fr*10^6/scale needs almost no states: multiply-by-10 on a decimal tape is a shift (append '0'), so "4807.038" → 48070380 µ° is a finite-state transducer — roughly a dozen states (scan integer part, mark point, shift fraction, pad zeros), alphabet {0–9, '.', ',', 'N', ␣}. The interesting question — is the 64-bit-safe conversion a *different machine* than the naive one? — dissolves: on a TM it is the *same* machine. The trap (48070380 × 10^6-ish intermediates > 2^32) exists only because C fixes word width; tape is unbounded, so "64-bit intermediate" is not a machine difference but a finite-word artifact of the compilation target. What changes between naive and safe is not states but the *constant* in the time bound. Verdict: the parser's real content is O(1) states; everything in the 150 cycles is word-size bookkeeping.

**Layer 2: keel counter.** Counting to N = 80,000,000 on one tape. Unary (linear) counter: 1 state, N cells — O(N) space. Binary counter: O(1) states (classic increment routine: walk to low end, flip trailing 1s→0s, flip first 0→1, return — ~4–6 states), space = log2(N) ≈ 26.3 ≈ 27 cells. So yes: counting to N is possible in O(1) states but *not* in o(log N) space — log N bits is the information-theoretic floor for distinguishing N configurations. Time: each increment is amortized O(1) (bit k flips every 2^k steps), so N increments cost ~2N head moves total — Θ(N) is unavoidable, one tape step per tick. That is exactly the ESP32's contract: N·d = 80M means the machine *is* the counter, prescaler d=80 just moves 27 bits of state into hardware. Software error 0 ppm because the TM and the timer do the identical Θ(N) walk.

**Layer 3: dispatch tick.** 100 cells + 200 edges = 300 input symbols. Unavoidable lower bound: Ω(E) head moves merely to *read* the program — information can't be acted on unvisited. On a single tape, random access costs O(tape length) per lookup, so a one-tape TM pays Ω(E·L); the RAM model's ~2,200 cycles (≈2 per symbol) is the artifact. The 9.2µs is physics; the Ω(E) scan is mathematics.
